Projektduplicator 2026 helps duplicate and edit EEP model projects.
The interface is available in German, English, French and Dutch. You can change the language while the program is running.
Model names and descriptions can be translated using Google Translate. This requires an internet connection. The feature uses the Google website and depends on its response format; it does not use an official Google API. If translation fails, the existing texts are retained.
The snapshot feature creates ZIP backups of projects.
The update buttons open a manual check for new GitHub releases. Updates are not checked automatically at startup.
Once a suitable release is available, it can be downloaded, verified and installed after confirmation. Existing settings and projects are preserved, and the program restarts after a successful installation.
